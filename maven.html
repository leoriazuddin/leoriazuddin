🚀 Beginner: What is Maven?

Maven is a powerful build automation tool for Java projects. It handles dependencies, builds, and project structure.

🔹 Install Maven

  1. Download from official site.
  2. Unzip and set the MAVEN_HOME environment variable.
  3. Add %MAVEN_HOME%/bin to your PATH.
  4. Check with mvn -version.

🔹 Create a Project

mvn archetype:generate -DgroupId=com.example -DartifactId=demo -DarchetypeArtifactId=maven-archetype-quickstart -DinteractiveMode=false

🧩 Intermediate: pom.xml Deep Dive

pom.xml is Maven's config file. Example:


<project>
  <modelVersion>4.0.0</modelVersion>
  <groupId>com.example</groupId>
  <artifactId>demo</artifactId>
  <version>1.0-SNAPSHOT</version>

  <dependencies>
    <dependency>
      <groupId>junit</groupId>
      <artifactId>junit</artifactId>
      <version>4.12</version>
      <scope>test</scope>
    </dependency>
  </dependencies>
</project>

🔹 Build & Run

mvn compile
mvn test
mvn package → generates target/demo-1.0-SNAPSHOT.jar

🏗️ Advanced: Plugins, Profiles, and Best Practices

🔹 Maven Plugins


<build>
  <plugins>
    <plugin>
      <groupId>org.apache.maven.plugins</groupId>
      <artifactId>maven-compiler-plugin</artifactId>
      <version>3.8.1</version>
      <configuration>
        <source>1.8</source>
        <target>1.8</target>
      </configuration>
    </plugin>
  </plugins>
</build>

🔹 Maven Profiles


<profiles>
  <profile>
    <id>dev</id>
    <properties>
      <env>development</env>
    </properties>
  </profile>
</profiles>

🔹 Best Practices

  • Keep dependencies up to date
  • Use a parent POM for multi-module projects
  • Don’t commit the target/ directory

🧠 Bonus: Use mvn dependency:tree to see your project's full dependency graph.
